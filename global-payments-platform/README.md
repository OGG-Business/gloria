# Global Payments Platform (SWIFT/IBAN)

A production-ready, open-source platform to initiate, track, and manage international bank transfers (SWIFT & IBAN), with special attention to banks operating in DRC.

- Backend: FastAPI (Python), PostgreSQL, SQLAlchemy, Alembic, Vault (hvac), Keycloak (OIDC).
- Frontend: React (TypeScript), Vite.
- Infra: Docker, docker-compose, Kubernetes (Helm), Prometheus/Grafana, EFK.

Important: This project includes a strict dry-run mode and requires manual operator action to send any real payment. Do NOT run in production without proper credentials, certificates, and written approval from your banking partner.

## Quick start (dev)

1. Prerequisites: Docker, Docker Compose
2. Start stack:

```bash
docker-compose up -d --build
```

3. Backend: https://localhost:8443 (OpenAPI UI at `/docs`)
4. Frontend: https://localhost:4443
5. Keycloak admin: https://localhost:8444 (dev only)
6. Grafana: http://localhost:3000, Prometheus: http://localhost:9090

Self-signed dev certs are generated by compose on first run.

## Project structure

See repository tree in this README end-to-end response. Key directories:
- `backend/`: FastAPI app and Alembic migrations
- `frontend/`: React app (Vite)
- `infra/helm/`: Kubernetes Helm chart
- `scripts/`: Utilities (certs, TLS tests, dry-run)

## Security notes
- All secrets are loaded from Vault or env at runtime; never commit secrets.
- TLS 1.3 is enforced; mutual TLS required for SWIFT adapter.
- Admin roles require MFA (configured in Keycloak).
- KYC documents are AES-256-GCM encrypted at rest.
- Audit logs are append-only.
